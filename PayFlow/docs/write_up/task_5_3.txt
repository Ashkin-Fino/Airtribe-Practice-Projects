CURL Commands:

1. Register User 1:

    Command: 
        curl -X POST http://localhost:8080/users \
        -H "Content-Type: application/json" \
        -d "{\"name\":\"Ashkin\",\"upiId\":\"ashkinfino421@oksbi-2\",\"balance\":5000, \"phoneNumber\":\"7965937564\"}"

    Output:
        {"userId":1,"name":"Ashkin","upiId":"ashkinfino421@oksbi-2","balance":5000.0,
        "phoneNumber":"7965937564"}

2. Register User 2:

    Command:
        curl -X POST http://localhost:8080/users \
        -H "Content-Type: application/json" \
        -d "{\"name\":\"Rajesh\",\"upiId\":\"rajeshc@okaxis\",\"balance\":7500, \"phoneNumber\":\"8294631051\"}"

    Output:
        {"userId":2,"name":"Rajesh","upiId":"rajeshc@okaxis","balance":7500.0,
        "phoneNumber":"8294631051"}

3. Get All Users:

    Command:
        curl -X GET http://localhost:8080/users

    Output:
        [{"userId":1,"name":"Ashkin","upiId":"ashkinfino421@oksbi-2","balance":5000.0,
        "phoneNumber":"7965937564"},
        {"userId":2,"name":"Rajesh","upiId":"rajeshc@okaxis","balance":7500.0,
        "phoneNumber":"8294631051"}]

4. Get User By ID:

    Command:
        curl -X GET http://localhost:8080/users/1

    Output:
        {"userId":1,"name":"Ashkin","upiId":"ashkinfino421@oksbi-2",
        "balance":5000.0,"phoneNumber":"7965937564"}

5. Send Money Transaction:

    Command:
        curl -X POST http://localhost:8080/transactions \
        -H "Content-Type: application/json" \
        -d "{\"senderUpiId\":\"ashkinfino421@oksbi-2\",\"receiverUpiId\":\"rajeshc@okaxis\",\"amount\":1000,\"note\":\"Insurance\"}"

    Output:
        {"transactionId":1,"senderUpiId":"ashkinfino421@oksbi-2","receiverUpiId":"rajeshc@okaxis",
        "amount":1000.0,"note":"Insurance"}
